## 1. PORTAL — МАРШРУТИ ТА СТОРІНКИ

> portal.workflo.space — для клієнтів (Company Owner + Company Members)

### Маршрути (React Router v6)

```
/login                      → Логін
/register                   → Реєстрація (+ referral code в URL: ?ref=workflo-A3K9XZ)
/forgot-password            → Відновлення паролю
/reset-password             → Новий пароль (по токену з email)
/invite/:token              → Прийняти запрошення до компанії

/                           → redirect → /orders
/orders                     → Список замовлень (головна)
/orders/new                 → Нове замовлення (або modal)
/orders/:id                 → Деталі замовлення

/billing                    → Рахунки та оплати
/documents                  → Всі документи

/settings                   → redirect → /settings/profile
/settings/profile           → Профіль
/settings/company           → Компанія
/settings/members           → Члени команди
/settings/security          → Безпека (пароль, Telegram)
/settings/notifications     → Нотифікації
```

### Kanban — деталі

**Колонки та маппінг статусів:**

| Колонка | Статуси | Колір |
|---|---|---|
| Вхідні | `new`, `in_review` | Сірий |
| В роботі | `approved`, `in_progress`, `on_hold` | Синій |
| Перевірка | `in_review_final`, `revision` | Жовтий |
| Готово | `done` | Зелений (лічильник, без карток) |

> `cancelled` — окрема вкладка якщо потрібно, або в фільтрі "Архів"
> `done` — не показуємо картки (їх може бути сотні) — тільки число

**Картка замовлення в Kanban:**

```
┌────────────────────────────────────┐
│ 🔴 [Високий]                       │
│                                    │
│ Автоматизація звітності Excel      │
│                                    │
│ ТОВ Ромашка                        │
│                                    │
│ [ПВ]  📅 20 квіт ⚠️  💬 3  📎 2  │
└────────────────────────────────────┘
```

- Кольорова смужка зліва = пріоритет
- Avatar виконавця (або кілька)
- Дедлайн (червоний + ⚠️ якщо прострочений або сьогодні)
- Кількість коментарів і файлів

**Drag & Drop (dnd-kit):**

```typescript
// При перетягуванні картки між колонками:
// 1. Оновлюємо UI одразу (оптимістично)
// 2. Визначаємо новий статус: початок "В роботі" → 'in_progress'
// 3. API: PATCH /orders/:id/status { status: 'in_progress' }
// 4. Якщо помилка — відкочуємо + toast.error

// Дозволені переходи — ті ж що і в ALLOWED_TRANSITIONS
// Якщо перетягнути не можна → картка повертається назад + toast.warning
```
