# 🧪 Сценарії ручного тесту за ролями

> Чек-лист для власника на staging. Кожна роль — окремий акаунт (seed: owner / executor / client;
> менеджера й учасника компанії створити інвайтом). Позначки: ⚠ — відома проблема ще не виправлена
> (посилання на знахідку [`AUDIT_2026-09-roles.md`](AUDIT_2026-09-roles.md)); ✅ — виправлено
> (зріз у дужках). Оновлюється разом із чергою ROLE-\* у [`ROADMAP.md`](ROADMAP.md).

## 1. Власник агенції (workspace)

1. ✅ Дашборд → «На перевірці → відкрити» → список відфільтровано (ROLE-NAV, D13).
2. Ліди → перетягнути по стадіях → «Виграно» → конвертація ⚠ нову компанію не створити (D4).
3. Замовлення → «Нове замовлення» → Специфікація → оцінка → «надіслати на погодження».
4. Призначити виконавців, теги, залежності.
5. Дошка: створити команду + ліда ⚠ задачу не створити (D3); порівняти з Команда→«Підрозділи» (C1).
6. Команда → «Запрошення» → запросити виконавця.
7. Після здачі виконавцем → «Прийняти» → DONE → Виплати.
8. Порівняти дебіторів (Білінг / Звіти / дашборд, C5) і виручку (MoM / Звіти / P&L, C6).
9. Налаштування: 6 табів, тест SMTP, Telegram.
10. Картка клієнта 360°: інвайт учасника, скидання пароля, секрети.

## 2. Менеджер (workspace)

1. ✅ Дашборд: лінку «відкрити проєкти» менеджеру немає (фінанси — власнику) (ROLE-NAV, D8).
2. ✅ Замовлення → «Нове замовлення» активне — менеджер бачить реєстр клієнтів (PERM-2, D2).
3. ✅ Клієнти — реальні назви компаній (PERM-2, D2).
4. ✅ Лід → конвертація: список компаній доступний (PERM-2, D2).
5. Замовлення: прийняти роботу ✓; ✅ проєкт показано назвою без лінку (ROLE-NAV, D8).
6. ✅ Команда → «Запрошення»: менеджер запрошує (PERM-2 `team.invite`); KPI-смуга виплат ⚠ 403 (D7 → PERM-3).
7. Картка виконавця: видно «нетто-виручку» — чи так задумано? (D12).
8. ✅ Відсутності: на власній заявці замість «Погодити» — «погоджує власник» (ROLE-NAV, D16).
9. ✅ Календар → нова подія без тосту (PERM-2, D2).
10. Профіль ⚠ «Заробіток» 403 (D7); ✅ Налаштування → «Акаунт»: сповіщення, Telegram, сесії (ROLE-NAV, D6).

## 3. Виконавець (workspace)

0. ✅ Фінанси закриті на бекенді: платежі, рахунки, P&L, гаманці, юр-особи, ціни послуг → 403 (PERM-2).

1. «Мої задачі» (це замовлення) vs `/board` «лише мої» (задачі) — плутанина (C4).
2. Замовлення → Чат, Час, таймер старт/стоп.
3. ✅ «Здати» — лише в картці «Приймання» (і після доопрацювання); у шапці — тільки дозволені переходи, без паузи/скасування (ROLE-NAV, D9/C3).
4. ✅ Канбан → недозволений drag дає підказку без запиту (ROLE-NAV, D9).
5. Дошка: створити задачу ⚠ ніде (D3).
6. Секрети: показати розшарений секрет (step-up).
7. ✅ «Команда» → свій підрозділ read-only / «вас ще не додано» (ROLE-NAV, D1).
8. Відсутності: подати заявку.
9. ✅ ⌘K не показує фін-проєкти (ROLE-NAV, D8).
10. ✅ Налаштування → «Акаунт»: сповіщення / Telegram / сесії (ROLE-NAV, D6).

## 4. Тімлід (виконавець, лід підрозділу)

1. Дошка → своя команда → «⚙ налаштувати дошку» → колонки ✓.
2. Чужої команди не видно ✓.
3. ✅ «Команда» → ростер свого підрозділу з позначкою «ви тімлід» (ROLE-NAV, D1).
4. Прийняти роботу учасника ⚠ 403 (D10 — рішення власника, чи може лід приймати).
5. Картка учасника `/team/:id` ⚠ редирект (D1).

## 5. Власник компанії-клієнта (портал)

1. Реєстрація / прийняття інвайту → банер підтвердження email.
2. Реквізити в «Налаштування акаунта» → звірити з «Моя компанія» (C10).
3. ✅ `/orders/new`: 5 секцій, файли, анкета (DSN-4).
4. ✅ Сповіщення → замовлення → таб «Кошторис» → «Погодити» / «Запросити правки» (DSN-4).
5. Білінг → погодити рахунок; «Як оплатити»; оплата бонусами.
6. ✅ Документи: групи по замовленнях, «Договори», «Прийняти», «Оплатити» (DSN-5).
7. ✅ Проєкти: картки, години циклу, модалка (DSN-5).
8. Гаманець, лояльність, реферал (копіювати посилання).
9. Учасники → інвайт ⚠ немає видалення/ролей/прав (D5).
10. Секрети: створити → показати → журнал.
11. Підтримка, зустріч; перемикач EN ⚠ нічого не змінює (D17).

## 6. Учасник компанії-клієнта (портал)

1. Прийняти інвайт.
2. Замовлення: суми видно, створення ✓.
3. Кошторис → «Погодити» ⚠ 403 (D5).
4. «Оплатити» ⚠ вічний skeleton (D5).
5. Рахунки / Гаманець / Реферали ⚠ помилка + тости (D5).
6. ✅ Проєкти → стан «бачить власник» замість «проєктів нема» (DSN-5).
7. Лояльність ⚠ «—» (D5).
8. «Моя компанія» ⚠ хибне «реквізити неповні»; реквізити в налаштуваннях ⚠ 403 (D5).
9. Секрети ✓ «лише власник».
10. Інбокс: сповіщення «Погодити», яке не виконати ⚠ (D5).
