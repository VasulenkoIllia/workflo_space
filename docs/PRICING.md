# WORKFLO.SPACE — Pricing & Positioning (HYPOTHESIS)

> ⚠️ **PHASE-1-BLOCKER DRAFT — рішення за власником.** Це робоча гіпотеза (аудит P7),
> не зафіксована модель. Її треба підтвердити ДО проєктування `UsageCounter` метрик,
> quota-значень (F2/E4) і SaaS-підписки (E2). Без неї quota-seam enforce-ить проти
> невизначених лімітів.

## 1. ICP (хто платить)

Гіпотеза: **малі/середні агенції автоматизації та digital-агенції в UA/CEE** (2–15 осіб),
які зараз жонглюють Notion + Telegram + таблицями + ручними інвойсами. Не enterprise.

## 2. Конкурентний клин (чому ми, а не SuiteDash/Bonsai/ClickUp/monday)

Горизонтальна широта фіч — найслабша позиція для малої команди. Defensible-вузол:

- **Telegram-native** (OTP-логін, нотифікації, ліди з Telegram) — критично для UA/CEE ринку.
- **UA payment/tax** (НБУ-курс, гривня+USD dual-currency, локальні реквізити/акти).
- **White-label з дня 1** (агенція = власний бренд для СВОЇХ клієнтів).

→ Позиція: «цифровий офіс агенції під твоїм брендом, з Telegram і українським білінгом»,
а не «ще один horizontal PM-tool».

> **РІШЕННЯ ПОТРІБНІ:** конкретні ціни, межі тірів, що саме входить у white-label-тір.

## 4. Метрика білінгу (що рахує UsageCounter) — РІШЕННЯ

Кандидати: **seats** (виконавці) · **активні клієнти** · **замовлення/міс** · storage.
Рекомендація: основна вісь — **seats** (просто й передбачувано для агенції), а
активні-клієнти/замовлення — як fair-use ліміти тіру. `UsageCounter.resource` уже
підтримує всі (`orders|seats|storage|leads|integrations`); треба обрати, ЩО enforce-ити.

## 5. Merchant of Record (MoR) — РІШЕННЯ (структурне!)

`Agency.billingCustomerId` названо під Stripe — але для **UA-резидента, що продає глобально**,
Stripe means самостійний VAT/податковий облік по юрисдикціях.

**Рекомендація: Paddle / LemonSqueezy (MoR)** — вони беруть на себе VAT/sales-tax і
виступають продавцем, що різко спрощує комплаєнс для соло-фаундера з UA. Оцінити комісію
vs Stripe. Це рішення формує модель даних підписки (E2) + dunning, тож зафіксувати РАНО.

> Примітка: клієнтський білінг (модуль 05 — агенція виставляє рахунки СВОЇМ клієнтам) —
> окреме від SaaS-підписки (агенція платить workflo). Не плутати.
