# workflo.space — Design Core

«Engineer's Cut» — термінальна естетика на теплих stone-нейтралях + лаймовий акцент,
шрифти Geist / JetBrains Mono / Caveat. Усе ядро читає колір **лише через `--wf-*`
токени** — ніколи не хардкодимо hex. Тема перемикається через `data-theme`, акцент —
через `data-accent` (6 свапабельних пресетів). Спробуй перемикачі **Theme / Accent /
Aesthetic** у тулбарі на будь-якій сторінці компонента.

> Джерело токенів: `docs/DESIGN_SYSTEM.md §3` + `packages/ui/src/styles/tokens.css`.
> Воркфлоу додавання компонента: `docs/UI_COMPONENTS.md`.

## Accent-пресети

Палітра свапабельна: інший вигляд = інший пресет, **без перемалювання екранів**.

<div className="wfp-root" style={{ display: 'flex', gap: 10, flexWrap: 'wrap', padding: 16 }}>

    ['Lime', '#A3D90D'],
    ['Amber', '#D97706'],
    ['Phosphor', '#16A34A'],
    ['Cyan', '#0891B2'],
    ['Magenta', '#C026D3'],
    ['Orange', '#EA580C'],
  ].map(([name, hex]) => (
    <div key={name} style={{ display: 'flex', alignItems: 'center', gap: 8, border: '1px solid var(--wf-border)', borderRadius: 999, padding: '6px 12px' }}>

      <span style={{ fontSize: 13, color: 'var(--wf-fg)' }}>{name}</span>
    </div>
  ))}
</div>

## Shape

- Radius: `--wf-radius` 8px (картки/інпути), `--wf-radius-btn` 6px (кнопки), pills 999px.
- Дві естетики shell: **A · Terminal** (macOS-chrome, кнопки в `[ ]`) та **B · Studio** (чисто).
